# Career Navigator Demo 🚀

AI-powered career roadmap generator with cinematic Streamlit interface and multi-agent reasoning.

**This is v2** — an enhanced rebuild of the original hackathon version with improved UI/UX and better architecture.

## Features
- 🎯 GitHub profile analysis
- 💼 Skill gap detection  
- 🗺️ 7-day adaptive roadmap
- 🧠 Live agent activity logs
- ✨ Cinematic AI interface
- 📊 Multi-agent reasoning system

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- **Frontend:** Streamlit (cinematic CSS animations)
- **Backend:** Python (modular analyzers & agents)
- **Architecture:** Multi-agent reasoning system
