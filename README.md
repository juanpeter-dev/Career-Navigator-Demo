# Career Navigator Demo 🚀

AI-powered career roadmap generator with cinematic Streamlit interface.

## Features
- GitHub profile analysis
- Skill gap detection
- 7-day adaptive roadmap
- Live agent activity logs
- Multi-agent AI reasoning

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
